## Invariants

### Privacy
- **No analytics row ever holds `user.pk`, IP, session key, User-Agent or Referer path/query.** The UA is read transiently to classify `pageview.dim2` as `bot`/`human` and dropped; the referrer is reduced to acquisition bucket (`dim1`) + bare host (`dim2`), in-site referrers are not recorded. Guarded by: `analytics/tests/test_middleware.py::test_referrer_intern_navigation_dropped`, `analytics/tests/test_referrers.py::test_host_strips_credentials_and_port`, `web/tests/test_analytics_ingest.py::test_the_endpoints_take_no_notice_of_who_is_asking`.
- **The SPA beacon (`/api/v1/analytics/pageview/`) reads nothing about the caller and stamps `dim2=human` by construction (reaching it means JS ran).** Why: until 2026-08-17 beacon rows had no class, so the digest — which filters `dim2="human"` — reported only Django leftovers (98 vs 399 real visits). Guarded by: `web/tests/test_analytics_ingest.py::test_a_beacon_pageview_counts_as_human`.
- **Public event ingest accepts only `clau ∈ web/api/analytics_ingest._PUBLIC_EVENT_KEYS` (closed allowlist); server-side events go through `register()` directly.** Why: rows live forever; new events need backend code first. Guarded by: `web/tests/test_analytics_ingest.py::test_an_unknown_event_key_is_refused`, `analytics/tests/test_ingest.py::test_event_unknown_clau_rejected`.
- **`analytics.events.register()` is fail-open (`update_or_create` + `F()` increment, IntegrityError retry, swallows DB errors, `n<=0` no-op) unless `force_raise=True`.** Why: analytics must never break a user flow. Guarded by: `analytics/tests/test_events.py::test_register_swallows_db_error_silently`, `::test_register_force_raise_propagates`.
- **`analytics.bots.BOT_UA_MARKERS` mirrors the Caddy `@bot` regex in `deploy/Caddyfile`; edit both.** Guarded by: `analytics/tests/test_bots.py::test_python_markers_match_caddyfile_regex`.
- **The middleware skips `/sitemap` as a prefix (not `/sitemap.xml`): `sitemap-*.xml` fetches are not pageviews.** Why: unknown-UA crawler fetches of the sub-sitemaps became the whole "top human pages" list (2026-08-17). Guarded by: `analytics/tests/test_bots.py::test_sitemaps_are_not_pageviews`.
- **Dimensions are truncated to 80 chars, never stored whole; non-string dims are dropped.** Guarded by: `web/tests/test_analytics_ingest.py::test_long_values_are_truncated_not_stored_whole`, `::test_non_string_dimensions_are_dropped_not_coerced`.

### Snapshots and collectors
- **`snapshot_pipeline` gauges are idempotent per `(data, clau, dimensio_1)` (unique constraint); rerunning a day overwrites, never duplicates.** Guarded by: `analytics/tests/test_snapshot.py::test_snapshot_runs_and_is_idempotent`.
- **External collectors (GSC, Bing, PSI, social) skip cleanly when their credential is absent and never log it; the social collector is fail-open per platform, but a GSC API failure with a credential present PROPAGATES (logged via `logger.exception`) so `tq-health` sees a FAIL instead of a silent empty day.** GSC uses OAuth *user* creds of `admin@topquaranta.cat` (ADR-0002) because `sc-domain:` properties cannot add a service account — a revoked token is the known failure mode (post-mortem 2026-05-20). Guarded by: `analytics/tests/test_recollir_metrics_gsc.py::test_gsc_fetch_failure_propagates_and_logs`.
- **Social publication counts come from `SocialPost` (one row per slot, `status=publicat`), not from `MetricaEsdeveniment(social_publicat)`.** See CLAUDE.md §6.

### Digest, health report, incidents
- **`enviar_digest_setmanal` reports the last complete Mon→Sun week (`today − (weekday()+7)`) against the seven days before it; gauges read the Sunday snapshot; "Setmana N" is the project week of the reported Monday. `_delta()` reports absolute moves when the change rounds under 1 % or the base < 10 — never a "0 %" for real movement.** Guarded by: `analytics/tests/test_digest.py::test_delta_reports_small_moves_instead_of_rounding_them_to_zero`, `::test_calendari_situa_cada_publicacio_al_seu_dia`.
- **`analytics/health_report.py` is stdlib-only (no Django) and owns the *presentation* of `tq-health`: `classify_cron` states OK/STALE/STUCK/SKIP/FAIL/WAITING/MISSING/ORPHAN/DISABLED; WARN threshold is per-cron `skip_concern` (default 3), CRIT fixed 10; MISSING escalates only when `max_age_h ≤ 48`; DISABLED still goes stale; watchdog CRIT escalates even when silenced.** Guarded by: `analytics/tests/test_health_report.py` (`::test_classify_*`, `::test_gather_surfaces_orphan_status_file`).
- **`anomaly_signature()` is a stable dedup key over anomaly identity (`(name, state)` + threshold booleans), excluding ages, counters and silenced non-escalating rows — so a persistent failure emails once.** Guarded by: `test_health_report.py::test_signature_ignores_age_and_error_count`, `::test_signature_excludes_silenced_nonescalating`.
- **`analytics/incidents.py` reads `errors.log(.1)` and the `tq-run` status files best-effort: a missing file is reported as "not read", never as zero errors; cron state is classified by the same `gather_crons` `tq-health` uses.** Guarded by: `analytics/tests/test_incidents.py::test_django_errors_missing_file_is_not_zero_errors`, `::test_cron_anomalies_survives_a_missing_status_dir`.

### GoAccess
- **`generar_goaccess` reads the live `topquaranta_access.log` plus rotated `topquaranta_access-<RFC3339>.log.gz` — and nothing else under `/var/log/caddy` (legacy vhost, default `access.log`, `cercol_api_*` all excluded); streams with `heapq.merge`, dedups on request identity; a corrupt segment is kept-partial, named and non-fatal; coverage interval is *reported* (summary + report title), never asserted.** Guarded by: `analytics/tests/test_generar_goaccess.py::test_glob_excludes_legacy_and_other_vhosts`, `::test_truncated_gz_keeps_what_it_could_read`, `::test_coverage_interval_is_reported_not_the_days_asked_for`, `::test_overlapping_segments_do_not_duplicate`.
- **The report HTML is served only through `IsStaff` at `/api/v1/staff/analytics/goaccess/`, never by Caddy.**

### YouTube daily report (temporary)
- **The report never computes a YouTube weekly itself: it reads `ranking.senyal_youtube.visualitzacions_setmanals`, the single implementation of the per-video delta (invariant and guards in `ranking.md` §YouTube as second source).** Why: two implementations of the same delta is how they drift, and this one had already been wrong twice (Andreu Valor). The report's local `_increments` serves the Last.fm series only.
- **The Last.fm reference snapshot is searched with `±_MARGE_DIES` (3).** Why: one missed cron run must not blank the "sense YT" column and credit every row to YouTube. Guarded by: `analytics/tests/test_informe_yt_top.py::test_a_missing_day_does_not_empty_the_lastfm_week`.
- **"Connected" = has an Art Track **or** an official lane, the same rule `obtenir_senyal_youtube` polls by (`_sense_video`); coverage and the action list share it.** Why: counting only `youtube_video_id` under-reported coverage and put already-measured songs on the work list. Guarded by: `analytics/tests/test_informe_yt_accions.py::test_a_song_measured_through_the_official_lane_is_not_a_task`.
- **The mail hands out `_ACCIONS_DIA` (10) research tasks, ordered artist-with-no-channel → blind song → own-channel (charting artists **order** that slot, they never filter it — every artist that ever charted is already reviewed, so `n_top > 0` killed the slot permanently), and the list drains: a song with a video or `youtube_revisat`, and an artist with a channel or `youtube_canal_revisat`, never come back.** Why: discovery finished the catalogue; what is left is human work, and a queue that cannot record "looked, there is none" repeats itself until it is ignored. Guarded by: `test_informe_yt_accions.py::test_an_answered_song_never_comes_back`, `::test_an_artist_with_no_channel_at_all_outranks_the_songs`, `::test_the_own_channel_slot_never_dies_just_because_nobody_charted`, `::test_the_list_says_how_much_is_left_so_ten_rows_are_not_read_as_done`.
- **The two artist slots (and `resten_artistes`) offer only `Artista.objects.public()`; song slots don't care.** Why: a cançó is verificada on its collaborators' merit, so its main artist can still be pendent (Sr. À, 22/08/2026) — and `/staff/artistes/sense-youtube` filters `aprovat=1`, so the row asked for a channel on a page where the artist does not appear, every morning. Decide the artist first. Guarded by: `test_informe_yt_accions.py::test_no_demana_el_canal_dun_artista_encara_pendent`.
- **New top-40 rows are split by cause — `noves_yt` (would not pass the combined floor without views), `noves_terra` (passes on plays alone; only the lower floor let it in), `noves_ordre` (reordering) — and the three sum to `noves`.** Why: the combined floor is in signal units, so a bare "+11 new" credits YouTube with rows the floor change brought. Guarded by: `test_informe_yt_top.py::test_the_chart_effect_separates_what_youtube_earned_from_what_the_floor_gave`.

## Traps
- **Case asymmetry between the two pageview writers:** the beacon lower-cases `path` (`_clean`), the middleware stores `request.path` verbatim. Mixed-case SSR paths and their SPA twins land in different rows; aggregate by `lower(dimensio_1)` when joining.
- Historic `pageview` rows before the bot/human split carry empty `dim2` ("unclassified") and cannot be reclassified — the UA was never stored.
- Telegram per-post engagement is impossible via the Bot API; `raw.not_supported` marks it — do not chart it as zero.
- GoAccess coverage is bounded by disk rotation (`roll_size 10MiB`, `roll_keep 30`, `roll_keep_for 90d`), not by `--days`; a crawler sweep can burn a segment in ~2 h.
- The YouTube report is deleted by removing its cron line (no config switch); `youtube_checked_at`/`youtube_matched_at` stay (ingest history).
