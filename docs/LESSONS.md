# Lessons (incident digest)

This digest replaces reading the full write-ups. One paragraph per incident,
chronological, with the lesson and the concrete guard (test id / health check /
config / ADR) that now catches the shape — every guard named here was grep-verified
in the repo on 2026-08-19. Full post-mortem texts live in `docs/archive/post-mortems/`
; incidents without a file carry their lesson only
here and in the doc that first recorded them (`docs/ops/runbook.md`,
`docs/architecture/*.md`, `docs/archive/architecture/*.md`).

## 2026-05-01 — `obtenir_novetats` hung 12 days while reporting OK
**What broke:** The hourly cron sat on a stale lock for ~12 days; the lock-skip path exited 0, so every tick logged `status=OK`. Nothing ingested. **Lesson:** "exit 0" is not "did work" — a skip path and a no-op run must be distinguishable from a healthy run in the status contract. **Guarded by:** `music.locks.SingletonLock` exits 75 → `tq-run` writes `SKIPPED_BY_LOCK`; `WORK_DONE=<n>` protocol + `consecutive_zero_work` in `bin/tq-run` / `analytics/health_report.py` (STUCK state); `tq-health --email-on-fail` hourly cron. Full write-up: `docs/archive/ops/runbook.md`).

## 2026-05-07 — Brand SVG rendered as a black blob via `innerHTML`
**What broke:** The HTML parser keeps the `style="fill:…"` string on SVG paths but never populates `.style`, so `getComputedStyle(path).fill` was black. **Lesson:** promote inline `style` fill/stroke to attributes before injecting SVG fragments; a mono variant only works because the export carries a stroked-outline layer. **Guarded by:** `web-react/src/components/TopQuarantaLogo.test.js` (14 vitest cases, run by `ci.yml`). Full write-up: `docs/archive/architecture/brand-logo.md` traps 2–3.

## 2026-05-19 — Three 500 bursts from `--reload` + unmigrated models
**What broke:** `Artista.imatge_url` (music 0072), `HistorialRevisio.reconsiderada` (0075), `SolicitudRevisio` (comptes 0018) each referenced by code before their migration ran; workers reloaded from server-side edits; ~30 admin mails. **Lesson:** `--reload` turns every uncommitted edit into a deploy; model + migration land in the same PR and deploy only via `tq-deploy`. **Guarded by:** ADR `docs/archive/decisions/0001-gunicorn-no-reload.md`; `deploy/topquaranta-web.service` without `--reload` synced by `bin/tq-sync-infra`; `test_deploy_safety.py::test_no_pending_model_migrations`. Full write-up: `docs/archive/post-mortems/2026-05-19-gunicorn-reload-incidents.md`.

## 2026-05-19 — DM-ping "demanar revisió" collapsed under real moderation
**What broke:** Gestors pinged the admin pseudo-user with a free-form DM; no scope, no state, no way to reconsider a rejected song — the operator escalated three batches by hand within ten days. **Lesson:** a flow must model the *receiving* actor (queue + state); a mid-sprint "must support batch" restriction re-opens the spec. **Guarded by:** ADR `docs/archive/decisions/0004-workflow-sollicituds-revisio.md` (`SolicitudRevisio`, `HistorialRevisio.reconsiderada`); `docs/policies/conventions.md` (Specs before sprints) mini-spec rule. Full write-up: `docs/archive/post-mortems/2026-05-19-workflow-sollicituds-redesigned.md`.

## 2026-05-21 — Bluesky silent for 5 days (60 s upload timeout, no retry)

## 2026-05-22 — black corrupted `deploy/cron-meta.json`
**What broke:** Passing a `.json` explicitly to `black` bypassed its include filter; it added trailing commas → invalid JSON. **Lesson:** never pass non-Python files as explicit args to formatters; let black discover files. **Guarded by:** `test_deploy_safety.py::test_cron_meta_json_consumed_by_tq_health` (parses the JSON); runbook rule. Full write-up: `docs/archive/ops/runbook.md`; `git rebase main` conflicted on every one. **Lesson:** don't branch off a long-lived branch near merge; recover with fresh branch + cherry-pick of the unique commits. **Guarded by:** no guard: process lesson only (`docs/archive/ops/runbook.md`).

## 2026-07-26 — Stalwart served an expired TLS certificate for a month
**What broke:** The cert-sync script copied PEMs into a directory Stalwart 0.16 never reads (config lives in RocksDB); it reported success on 26 Jun, and the April cert expired 26 Jul, blocking every mail client. **Lesson:** an ops script must assert the externally observable outcome (the cert *on the wire*), never the exit codes of the commands it ran. **Guarded by:** `music.health.check_tls_certs` / `scripts/health/tls_certs.sh` (`music/tests/test_health.py::test_tls_certs_unreachable_endpoint_is_never_ok`, config `tls_endpoints_vigilats`); `docs/policies/conventions.md` ops-scripts rule. ## 2026-07-27 — `tq-deploy` could not tell "unchanged" from "could not look"
**What broke:** `git diff | grep -q` inside an `if` escapes `set -e`; a git failure read as "nothing changed", skipped venv sync + SPA build and printed `✓ Deploy complete`. Also `script_stop` had been silently dropped by the ssh-action bump. **Lesson:** compute the changed-file list once, up front, and fail loudly (exit 7). **Guarded by:** `bin/tq-changed-files` + `test_deploy_safety.py::test_tq_changed_files_fails_loudly_when_the_diff_is_not_computable`; `set -e` + absolute path in `deploy.yml`. Full write-up: `docs/archive/ops/runbook.md`; rotation at 10 MiB left a sliver, reported as exit 0. **Lesson:** read the rotated segments (and only this vhost's), report the coverage interval, never assert it. **Guarded by:** `analytics/tests/test_generar_goaccess.py::test_glob_excludes_legacy_and_other_vhosts`, `::test_coverage_interval_is_reported_not_the_days_asked_for`. Full write-up: `docs/archive/architecture/analytics-goaccess.md`.

## 2026-08-15 — Six DRF throttles inert since May
**What broke:** Subclasses of `ScopedRateThrottle` read `view.throttle_scope`, which no `@api_view` sets, so every limiter allowed everything. **Lesson:** a limiter must be proven to refuse in a test; declare scope on the class. **Guarded by:** `web/tests/test_throttles.py::test_no_throttle_relies_on_a_view_attribute_nobody_sets`, `::test_every_throttle_declares_a_scope_with_a_configured_rate`, `::test_the_login_throttle_stops_credential_guessing`. Full write-up: `docs/archive/architecture/comptes.md` § throttles.

## 2026-08-15 — Bocc/Rosalía inversion: recompute read its own freshly saved rows
**What broke:** `calcular_top` saved each territori before the next read, so a re-run's past-top penalty saw the current week and penalised #1 more than #2. **Lesson:** every historical read excludes the week being computed. **Guarded by:** `ranking/tests/test_coherencia_ranking.py::test_recalculating_the_same_week_is_idempotent`. Full write-up: `docs/architecture/ranking.md`.

## 2026-08-16 — 2FA challenge screen had no rate limit
